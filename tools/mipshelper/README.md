# MipsHelper369

Course-provided assembler that converts MIPS assembly into instruction and data memory contents for the Verilog memories (hex, binary, or `memory[i] = ...` initializers, optionally with the source line as a comment). See `docs/course-materials/mipshelper-tutorial.pdf`.

Written for ECE 369A at the University of Arizona; see the header of `src/MipsHelper.java` for authorship and copyright. Included unchanged.

| Path | Contents |
| ---- | -------- |
| `bin/src/MipsHelper369.jar` | Prebuilt application |
| `bin/mipsHelper369` | Launcher script (`java -jar src/MipsHelper369.jar`), run from `bin/` |
| `bin/isa.data` | Instruction set definition read by the tool |
| `bin/mipsHelper369_v3.tgz` | Original distribution archive |
| `src/` | Java source and makefile |

```sh
cd tools/mipshelper/bin
./mipsHelper369
```

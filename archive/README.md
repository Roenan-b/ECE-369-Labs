# Archive

Working drafts, alternates, and intermediate snapshots from the course, kept so the development history stays browsable. Nothing here is built by the Makefile, and much of it does not compile on its own. The maintained sources for each lab are under [`../labs`](../labs).

Files keep their original names (with spaces removed and file extensions added) so they can be traced back through `git log --follow`.

| Path | Contents |
| ---- | -------- |
| `lab03/datapath-early/` | First versions of the datapath components and an ALU template |
| `lab03/datapath-alternates/` | An alternate ALU and alternate ALU, register file, and data memory testbenches |
| `lab03/asm-drafts/` | Earlier VBSME and SAD assembly drafts |
| `lab04-05/components/` | Standalone ALU, controller, and pipeline-register work before integration |
| `lab04-05/top-level-drafts/` | Candidate top-level and fetch-unit designs |
| `lab04-05/jal-support/` | Pipeline registers, controller, and muxes extended for `jal` |
| `lab04-05/snapshot-*` | Full working-set snapshots, by date |
| `lab04-05/top-level-draft-2025-11-06/` | Alternate top level with display wiring |
| `lab06/snapshot-*` | Lab 6 working-set snapshots, by date |
| `lab06/post-lab-2025-11-24/` | `toplevel.v` between the Lab 6 and Lab 7 versions |
| `lab07/memory-image-drafts/` | Earlier instruction and data memory images for Lab 7, including annotated and `memory[i] = ...` initializer forms |
